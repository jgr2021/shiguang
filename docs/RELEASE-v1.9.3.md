# 拾光 v1.9.3 · 更轻的待办编辑

- 编辑待办只保留内容、日期、时间、重要标记和保存操作；去掉大标题、装饰说明与多余滚动区域。
- 待办旁边直接点 **删除**，无需打开编辑窗口或确认弹窗。
- 列表下方出现 **撤销**。连续删除时可逐条恢复，本次打开期间不会自动消失。
- “所有待办”和当天列表使用相同操作，三种界面语言均支持。

撤销队列只在本次打开期间保留，退出应用或切换账号后清空。删除及恢复仍按原有 GitHub 同步流程处理；同步冲突继续通过现有冲突机制处理。
