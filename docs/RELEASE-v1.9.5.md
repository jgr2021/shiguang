# 拾光 v1.9.5 · 聚焦本周待办

右上角的待办入口改为 **本周待办**，仅显示当前自然周（周一至周日）加上今天前两天的安排。

例如今天为2026年10月26日，范围是 **10月24日至11月1日**。窗口会直接显示日期范围，未完成数量、今天、本周接下来、过期及已完成分类都采用同一个范围。跨日后随今天更新。

其他日期的待办仍保留在原日期，可从月历或搜索查找；此变化不删除、改期或完成任何待办。
