# 拾光 Shiguang

## 安排今天，記住生活。

一個放在電腦裡的日曆、日記本和資料夾。記下待辦、突然的想法和每天的小小進展。沒有網路，也能繼續記錄。

**[下載 Windows 安裝版 · v1.8](https://github.com/jgr2021/shiguang/releases/download/v1.8.0/Shiguang-Setup-1.8.0-x64.exe)** · [免安裝 ZIP](https://github.com/jgr2021/shiguang/releases/download/v1.8.0/Shiguang-1.8.0-Windows-x64.zip)

Windows 10 / 11 · 64位 · 預覽版 · [简体中文](../README.md) · [English](README.en.md)

![日曆與當天待辦的實際介面，內容為虛構示例](media/app-calendar.png)

## 從一件小事開始

1. 安裝後開啟拾光，在歡迎頁選擇繁體中文，再點「先開始記錄」。不需要寫程式或安裝 Python。
2. 回到今天，輸入一件待辦，按 Enter 加入。需要時再補上時間與備註。
3. 切到當天日記，留下一句話。草稿會自動儲存在本機。

## 陪你度過普通的一天

- 早上，替今天要做的事排個順序。
- 白天，記下靈感、閱讀筆記或工作進展。
- 把旅行清單、課程資料連到一個或多個日期。
- 想找舊內容時，試試標題、備註或正文中的關鍵字。
- 在設定裡匯出完整備份，替記錄多留一份副本。

## 想用 AI 時，再讓它幫忙

連接自己的 AI 服務或本機 Codex 登入後，可請助手回顧一週、起草日程，或根據舊履歷與後續成果整理新版本。**日程先預覽、修改，再由你確認寫入。** Enter 傳送，Ctrl+Enter 換行。

AI 需要網路與自己的服務商額度；使用助手時，問題、近期對話與相關記錄會傳給所選服務商。一般記錄不需要 AI。

目前為未簽署的預覽版，尚無到點提醒、手機版、自動跨裝置同步、掃描文字辨識或內建網頁搜尋。
