# 拾光 v1.9.0 · Preview

**不登录，也能一直使用本机日历。** 本版汇集 v1.8 之后的界面改进，并加入可选的 GitHub 私有仓库同步预览代码。

## 更顺手的日常记录

- 月历格子直接显示待办时间与标题、日记节选、附件名称。
- 左侧月历扩大，移除顶部标语和底部快捷键说明。
- 待办按 Enter 保存，日期与时间在当前窗口内选择，不再挤下表单。
- 附件标题不会误触打开；月历附件定位到当天列表，打开文件使用明确按钮。
- 搜索默认按上传时间由近到远列出全部附件，也能搜索“全部附件”。
- 月历显示中国大陆 2026 年节假日、放假与补班标记；其他年份尚未配置官方调休表。

## GitHub 同步：可选预览，尚未接通

设置中新增 GitHub App 设备登录、账号隔离、私有仓库选择、记录合并和冲突选择界面。**发行包暂不包含已注册的 GitHub App 信息，维护者注册及真实账号、双设备验证仍待完成。** 本机使用可以跳过此入口。

实现范围包括文字记录、待办和小附件；单附件上限 10 MiB、合计 100 MiB、最多 1,000 个。AI 密钥、助手聊天及 Agent 自动任务配置不参与同步。GitHub Token 本机加密保存；默认短期令牌到期需重新授权。私有仓库内容没有端到端加密，Git 历史可能保留删除前的内容。

详见 [GitHub 同步说明](../GitHub同步说明.md) 与 [本版完成范围](QA-v1.9.0.md)。

## 下载与升级

- **通常下载：** `Shiguang-Setup-1.9.0-x64.exe`，适用于 Windows 10/11 x64。
- **免安装：** `Shiguang-1.9.0-Windows-x64.zip`，完整解压，保留 `_internal` 文件夹。
- `SHA256SUMS.txt` 提供上述文件的 SHA-256 校验值。
- 更新前可在设置中导出完整备份。升级程序使用原有数据目录；无需 GitHub 登录。
