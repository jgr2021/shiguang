# 拾光 v1.8.0 · 点选日期与时间

安排一件小事，无需记住输入格式。

- **日期点月历**：普通待办与 AI 日程草案共用日期选择，今天、明天一键选择。
- **时间直接点选**：小时、常用分钟按钮，支持全天和 1 分钟微调。
- **附件更好整理**：标签直接多选；月历点选多天、多段连续范围。移除两个选填输入项。
- **日记写完即保存**：主页移除归档按钮，旧历史记录仍可搜索。
- **细滚动条**：简化长表单的视觉，保存和取消保留在底部。
