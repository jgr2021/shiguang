# 常见问题

[返回介绍](../README.md) · [第一次使用](QUICKSTART.md)

## 我不会编程，能用吗？

能。下载 Windows 安装版即可，不需要装 Python、打开终端或看源码。

## 收费吗？

当前程序可直接下载安装，基础记录不需要注册或购买 AI 服务。在线助手使用你自己的服务商账户，额度、收费及条款由该服务商决定。软件没有共享免费密钥。[免费额度筛选](FREE-AI.md)。

## Mac 下载哪个？

M 系列选 arm64 DMG，Intel 选 x86_64 DMG；当前要求 macOS 15 或更新版本。打开 DMG，把 App 拖入应用程序。Mac 包尚未经过 Apple Developer ID 签署或公证，完整说明见 [Mac 安装说明](../MACOS-START.md)。

## 断网会丢记录吗？

日历、待办、日记、附件与本机搜索不依赖网络。日记草稿自动保存；出现保存失败提示时，先复制未保存文字，检查磁盘空间。AI 问答需要网络。

## 日记存在哪里？会发出去吗？

Mac 新安装默认放在 `~/Library/Application Support/Shiguang/data`，密钥使用系统钥匙串。Windows 新安装默认放在当前用户的 `%LOCALAPPDATA%\Shiguang\data`，可以从设置打开数据目录。记录日记本身不会自动调用在线 AI。

主动使用拾光助手时，问题、近期对话和完成请求所需的相关档案会发送给你选定的服务商。API Key 在 Windows 上加密保存，普通备份不包含它；换电脑需要重新填写。

## 日记还需要点击归档吗？

不需要。写完会自动保存在本机。旧版本留下的历史档案仍可通过搜索查看。

## 文件能关联多个日期吗？

能。添加附件时，可以直接点选多天，也可以在月历中点选多段连续范围，无需手写日期格式。扫描图片里的文字暂不支持 OCR；搜索可用文件名、备注及成功提取的正文。

## 怎样备份、升级或换电脑？

在 **设置 → 导出完整备份** 保存 ZIP，备份包含待办、草稿、档案、附件、对话和生成文档。更新前建议保存一份。

升级运行新版安装包；程序与个人数据分开保存。恢复备份目前需要关闭应用、保留原数据目录副本，再按备份原结构恢复文件，尚无一键恢复向导。具体目录说明见[完整使用说明](../开始使用.txt)。

推荐给朋友时，分享[产品下载页](https://jgr2021.github.io/shiguang/)即可；自己的数据目录和备份留给自己。

## 能自动提醒、同步手机、连接云盘吗？

当前没有到点弹窗提醒或手机版。GitHub 私有仓库同步是可选预览功能，已内置公开应用配置，Mac 与真实双设备同步仍待验证；本机使用无需登录。云文件功能可把附件导出到已有网盘客户端的本机同步文件夹；是否上传完成，以网盘客户端显示为准。它不是整个日历数据库的双向同步。

## GitHub 同步会把日记公开吗？

设计上只允许关联自己拥有的私有仓库，首次加入本机记录需要明确选择。发行包已内置公开应用注册信息，已核对单台 Windows 文字记录与云端一致。单附件50 MiB、当前附件合计500 MiB；Git 历史另计，所有同步设备需一起升级至1.9.2或更新版本。仓库内容未做端到端加密，Git 历史也可能保留删除前的内容；请先阅读 [同步说明](../GitHub同步说明.md)。不启用同步时，继续完全本机使用。

## AI 会擅自改我的安排吗？

当前 AI 只生成新增待办草案，预览时可以修改或取消勾选。点击“确认写入日历”后才保存。已有待办不会被模型自动改期、删除或勾选完成。

## AI 连接不上怎么办？

- **Codex：** 选择“本机 Codex 登录”，先读取状态；需要已安装 CLI、完成登录且账户有可用额度。
- **其他服务：** 核对 Key、服务商地址、账户地域和模型，再检查连接。401 常见于密钥问题，429 常见于额度或频率限制。
- 模型目录能读取，不代表每个模型都有调用权限。连接检查只发送简短文字，不附日记。

[完整连接指南](../AI连接指南.md)。反馈时不要贴出 Key 或私人档案。

## 下载的几个 ZIP 有什么区别？

`Shiguang-1.9.2-Windows-x64.zip` 是程序，完整解压后打开 `Shiguang.exe`。GitHub 的 `Source code (zip)` 和 `Code → Download ZIP` 是源代码，普通使用者无需下载。

## 这版还有哪些限制？

目前是未签名预览版，尚未完成全新电脑安装/卸载及所有输入法、显示器组合验证。没有内置网页搜索、扫描件 OCR 和自动更新。Codex、GitHub、ChatGPT、WorkBuddy 的其他工作记录尚未自动同步。[本版完成范围](QA-v1.9.2.md)。
