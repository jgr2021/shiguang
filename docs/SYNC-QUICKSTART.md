# 拾光 GitHub 同步：普通用户上手与排错

适用 **v1.9.2**，更新于2026-10-14。[下载程序](https://github.com/jgr2021/shiguang/releases/tag/v1.9.2) · [返回使用指南](QUICKSTART.md)

## 先看这三句话

- **只在本机记录：安装后直接用。** 日历、待办、日记、附件和搜索不需要GitHub账号或网络。
- **想跨电脑同步：首次需要登录、创建私有仓库并授权。** “仓库”在这里就是你自己的线上资料夹；每个用户使用自己的账号和仓库。
- **普通用户不用注册GitHub App、生成私钥、填写Client ID或购买AI Token。** 官方v1.9.2安装包已内置公开应用配置；同步与AI设置是两件独立的事。

当前同步仍是预览功能，首次配置需要在拾光与GitHub网页之间切换。网络不稳定、登录过期或附件超限时，可能需要手动处理。

## 第一次设置：照着六步做

### 1. 安装完整程序

在[下载页](https://github.com/jgr2021/shiguang/releases/tag/v1.9.2)选择适合自己电脑的版本：

| 电脑 | 下载文件 |
| --- | --- |
| Windows 10/11，64位 | `Shiguang-Setup-1.9.2-x64.exe`；免安装用户选择Windows ZIP并完整解压 |
| Mac M系列，macOS 15或更新 | `Shiguang-1.9.2-macOS-arm64.dmg` |
| Mac Intel，macOS 15或更新 | `Shiguang-1.9.2-macOS-x86_64.dmg` |

GitHub页面上的`Source code`是源码，普通使用者下载上表的程序。免安装版请保留整个文件夹，不能只复制EXE。[Mac安装说明](../MACOS-START.md)

### 2. 在拾光登录自己的GitHub账号

打开 **设置 → 账号与同步 → 用 GitHub 登录 / 切换账号**。

点击 **复制验证码并打开 GitHub**，在网页粘贴验证码并完成授权，确认网页当前登录的是你自己的账号。返回拾光后应看到 **已登录……，请选择专用私有仓库**。

### 3. 创建自己的私有资料仓库

在拾光点击 **创建专用私有仓库**，或打开[GitHub创建仓库页面](https://github.com/new)。按下面填写：

| 页面字段 | 选择或填写 |
| --- | --- |
| Owner | **你自己的个人账号**；本版同步不支持组织仓库 |
| Repository name | `shiguang-data` |
| Visibility | **Private（私有）** |
| Add README | **开启／勾选** |

点击 **Create repository**。完成后应看到 **你的用户名/shiguang-data**，旁边标注 **Private**。如果已经建好了这个私有仓库并有README，可以直接使用。

### 4. 只授权这个仓库

回到拾光，点击 **授权这个仓库**，进入[拾光应用安装页](https://github.com/apps/shiguang-diary-sync/installations/new)。

1. 选择自己的个人账号。
2. 选择 **Only select repositories（仅选定仓库）**。
3. 在列表里选 **你的用户名/shiguang-data**。
4. 核对权限：**metadata只读、code读写**，点击 **Install**；如果是修改已有安装，则点击 **Save**。

这里的code读写权限用于保存日记和附件文件。不要选择公开的软件源码仓库`shiguang`，也不需要选择All repositories。GitHub的应用安装和网页登录授权是两个步骤，只看到“Installed”还不表示拾光已经开始同步。[GitHub安装说明](https://docs.github.com/en/apps/using-github-apps/installing-a-github-app-from-a-third-party)

### 5. 回到拾光，关联并启用同步

点击 **刷新仓库列表**，选择 **你的用户名/shiguang-data**。

如果这台电脑已经记了一些内容，并且希望一起同步，在首次关联时勾选 **将当前本机记录加入此账号（首次关联）**。不勾选会使用独立的账号资料空间；原本机记录仍保留，但不会自动加入该账号。

点击 **关联并启用同步**，核对确认框中的账号、私有仓库和资料目录后确认。

### 6. 看见成功提示，再判断已接通

在 **设置 → 账号与同步** 点击 **立即同步**，等待出现 **已同步……条记录**，并核对 **上次同步** 的时间。

- 如果下面还提示有附件仅保存在本机，说明这些附件没有上传。
- 也可以打开自己的私有仓库，查看是否出现`shiguang-sync`文件夹；首次启用后只有README，通常表示还未完成首次同步。
- 不要直接编辑或删除仓库里的同步文件。日常记录继续在拾光中修改。

## 换另一台电脑

两台电脑都使用 **1.9.2或更新版本**。先在第一台完成一次成功同步；第二台安装后登录**同一个GitHub账号**，选择**同一个私有仓库**，关联并立即同步。不必重复创建仓库。

第二台若已经有本机记录，需要自己决定是否在首次关联时加入。出现冲突时，打开 **处理同步冲突** 核对并选择保留的版本。建议开始时不要在两台电脑同时编辑同一条记录。

## 使用中最容易遇到的情况

| 看到的情况 | 怎么处理 |
| --- | --- |
| 提示填写Client ID、创建GitHub App或“尚未配置” | 下载官方1.9.2或更新的完整程序包；ZIP完整解压，Mac整体替换App。普通用户不用注册开发者应用。仍有提示时反馈版本与截图。 |
| 找不到`shiguang-data`，仓库列表为空 | 确认它属于当前登录的个人账号、是Private、有README，而且已在拾光App安装设置中授权；保存后回拾光刷新列表。 |
| 授权错了`shiguang`或其他仓库 | 打开[GitHub已安装应用](https://github.com/settings/installations)，找到Shiguang Diary Sync，进入Configure；只保留自己的`shiguang-data`并Save。回到拾光刷新。 |
| 仓库没有分支、关联时报错 | 在GitHub为仓库添加README并提交，再回拾光重试。 |
| GitHub网页已显示Installed，软件却未同步 | 继续完成上面的第5、6步：软件内关联仓库并立即同步。 |
| 连接超时、暂时无法连接GitHub | 先确认网络能访问GitHub；等待当前请求结束，再点立即同步。网页能打开不保证接口每次可达。反复失败时保留报错并反馈，不需要反复卸载或新建仓库。未上传的修改仍保存在本机。 |
| 登录已过期、需要重新登录 | 再点 **用 GitHub 登录 / 切换账号**，授权同一账号，再选择并关联原来的仓库。当前版未实现自动续期，默认授权令牌约8小时过期；不用重建仓库。 |
| 提示附件仅保存在本机 | 单个文件超过 **50 MiB** 时会跳过；可以上传压缩后的较小版本，或保留本机、通过其他云文件服务分享。不会自动拆分文件。 |
| 总量超限，整次同步停止 | 当前附件合计最多 **500 MiB**、最多1000个。先导出完整备份，再决定精简哪些附件；不要直接删除GitHub同步目录。删除已同步附件可能传播到其他设备。 |
| 登录后看不到原来的本机记录 | 首次关联可能未勾选“将当前本机记录加入此账号”。退出账号回到本地空间查看并备份原记录；当前版没有已关联后的“一键合并本机空间”入口，联系维护者协助处理，保留原资料目录。 |
| 两台电脑内容不同、提示冲突 | 两边都升级，核对账号与仓库一致，检查同步时间；有冲突就到 **处理同步冲突** 选择版本后重试。 |
| 关闭软件后没有继续同步 | 自动同步仅在拾光运行且联网时进行，正常约每2分钟一次；失败后会延长重试间隔。关闭前可手动同步并确认成功。 |

登录期限依据：[GitHub用户令牌说明](https://docs.github.com/en/apps/creating-github-apps/authenticating-with-a-github-app/refreshing-user-access-tokens)。设备授权流程可以实现无需开发者密钥的续期，但拾光1.9.2尚未实现此功能。

## 分享给朋友时

发送[程序下载页](https://jgr2021.github.io/shiguang/)和本页链接即可。朋友使用自己的账号、自己的私有仓库和自己的AI配置。请分享官方下载包，自己的资料目录与备份留给自己。

需要反馈时，提供：**系统、拾光版本、出错步骤、报错原文、上次同步时间**。截图遮住日记原文和私人文件名，不发送密码、Token或私钥。[提交问题](https://github.com/jgr2021/shiguang/issues/new?template=problem.yml)

## 当前完成范围

已核对单台Windows的文字记录和11 MiB附件与私有仓库一致；曾发生网络中断，经维护脚本重试后完成。**尚未完成另一个普通用户账号的独立上手验收、Mac实际桌面验收、双设备同步和容量边界测试**，不能保证其他用户不会遇到问题。Windows未签名，Mac未完成Apple Developer ID签名或公证。详见[版本验证记录](QA-v1.9.2.md)。

私有仓库不是端到端加密存储，Git历史也可能保留被删除的内容；500 MiB仅指当前附件总量，历史占用另计。完整同步范围、退出账号和数据位置见[详细说明](../GitHub同步说明.md)。
