# 拾光 v1.9.4 · 按钮更清楚，编辑更紧凑

- **更好点按：** 列表里的编辑、删除改为并排大按钮，文字加大，点击区域扩大。
- **颜色区分：** 编辑使用浅绿底，删除使用浅红底；悬停时保持各自色系。
- **减少留白：** 编辑窗口高度随内容确定，删除、取消、保存紧跟表单；不再预留空的错误提示行。

直接删除不弹确认窗口，误删可在列表下方撤销；撤销记录保留到本次应用退出或切换账号。输入框中仍可按 Enter 保存。
