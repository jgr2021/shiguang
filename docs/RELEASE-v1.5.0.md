## 拾光 Shiguang v1.5.0 · Windows 三语预览版

离线日历、日记、多日期附件，以及使用自己 API Token 的个人 AI 助手。

### 下载

- **Shiguang-Setup-1.5.0-x64.exe**：推荐，安装后从桌面打开，无需 Python 或 Codex。
- **Shiguang-1.5.0-Windows-x64.zip**：完整解压后运行其中的 Shiguang.exe，保留运行库目录。
- **SHA256SUMS.txt**：安装包与 ZIP 校验值。

适用于 Windows 10/11 x64，支持简体中文 / 繁體中文 / English。

### 这版更新

- 弹窗按所属窗口居中，统一标题、间距、按钮和配色。
- 所有待办改为统计卡、日期分组和五种筛选，增加空白页引导。
- 附件、搜索、聊天和设置布局同步打磨。
- 保留离线记录、多日期附件、模糊搜索、个人 AI 和简历更新功能。

### 开始使用

先离线记录即可。需要 AI 时，在设置中填写自己的服务商、模型和 Token；请求费用由该账户承担。上传旧简历后，可在助手中请求结合后续记录生成新版本。

这是未签名预览版，已编译打包并展示界面，尚未完成完整功能测试、全新电脑安装/卸载测试和真实服务商 API 测试。API 模式没有内置网页搜索；网盘功能通过用户自己的同步文件夹工作。

包内没有作者的私人档案、附件、Token 或聊天自动任务。新安装将个人数据存储到当前 Windows 用户自己的数据目录。
