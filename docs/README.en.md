# Shiguang

## Plan today. Keep a little of life.

A Windows and Mac calendar, journal and place for date-linked files. Write down a task, a passing thought or a small step forward. Core features work offline, without creating an account.

## Start with one small thing

1. Install and open Shiguang. Choose English on the welcome screen, then start recording. No Python or coding knowledge needed.
2. Go to today. Type a task and press Enter to add it. Choose a time in the same window when useful.
3. Open the daily journal and write a sentence. Drafts save locally as you write.

## Make room for everyday life

- Keep work tasks, errands and personal plans in one calendar.
- Write freely: an idea, a reading note, a small achievement.
- Attach a document once and link it to several dates.
- Search titles, notes, extracted text and common synonyms.
- Export a complete backup from Settings.

## AI, when you want it

Connect your own AI provider or an existing local Codex sign-in. Ask for a weekly review, a calendar draft, or a new résumé based on records you provide. **Review and confirm calendar drafts before they become tasks.** Enter sends; Ctrl+Enter adds a line break.

AI requires a network connection and your own provider quota. Your question, recent conversation and relevant records are sent to the provider when you use the assistant. Basic recording does not require AI.

This is a preview: Windows is unsigned; Mac builds use ad-hoc signing and have no Apple Developer ID or notarization. Optional GitHub private-repository sync includes public app configuration: 50 MiB per attachment, 500 MiB total current attachments, excluding Git history. All syncing devices need version 1.9.2 or newer. Windows text-record consistency has been checked; Mac, capacity boundaries and two-device synchronization still await validation. Local use requires no login. This release was built but has not undergone new automated tests or full UI validation. Timed notifications, a mobile app, OCR and built-in web search are not included. ## Editing and removing tasks

Use **Edit** beside a task for a compact editor; press Enter to save. **Delete** removes the task immediately without a confirmation window. Use **Undo** below the list to restore deletions one at a time. Undo is available during this app session and is cleared when you exit or switch accounts.

## This week's task overview

The header's **This week** view shows Monday–Sunday of the current week, plus the two days before today. Counts and all filters use that same range, which is displayed in the window. On October 26, 2026, this means October 24–November 1. Tasks outside the range remain accessible in the calendar and search.
