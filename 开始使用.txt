拾光日历 1.9.0 · 预览版
每天一点，慢慢向前。

日期点选月历；时间点选小时与分钟，支持全天和 1 分钟微调，无需手写格式。

【安装与开始】
适用于 Windows 10/11 64位。安装后从桌面或开始菜单打开“拾光日历”。
无需安装 Python；使用服务商 API 时也无需安装 Codex。
第一次打开可以先离线记录，也可以进入“设置 → AI 服务与 Token 设置”。
本安装包是未签名预览版，尚未完成全新电脑安装验证。各 AI 服务的验证范围见版本说明。

【语言】
支持简体中文、繁體中文和 English。安装时可选择语言，首次打开会沿用。
首次启动页或“设置”顶部选择语言，再点“应用语言”，立即切换并自动记住。
切换前会保存当前随记；若有其他编辑窗口或正在处理文件/请求，请先完成再切换。
界面、日历日期、附件、搜索、设置和助手提示随语言切换。
助手默认使用所选语言回复与生成文档，也可在提问时明确指定其他语言。
原有日记、待办、文件内容和历史对话保持原文；系统文件选择框的按钮由 Windows 语言决定。

【日历与附件】
选一天，记录待办和随记。日记自动保存在本机，无需另外归档。
绿色“回到今天”或 Ctrl+T 可跳回今天，今天的格子有明显标记。
当天“附件”支持上传文件。标签直接点选；在月历中点选多天，或切换“连续日期”选开始和结束。
顶部“搜索”可查标题、正文、备注、随记与待办，离线可用。
扫描件暂不做 OCR；正文提取状态会显示在附件详情。
基础记录、附件、搜索与备份均可离线使用。

【使用自己的 AI Token】
1. 在对应服务商的 API 控制台创建自己的 API Key / Token。
2. 打开“设置 → AI 服务与 Token 设置”，选择服务商。
3. 填 API 基础地址、账户可用的模型名称、自己的 Token，然后保存。
4. 可点击“检查连接”：只发送简短检查文本，可能产生少量费用，不发送档案。
5. 打开“拾光助手”，输入问题，或点击“更新我的简历”后发送。

预置 OpenAI、Claude、Gemini、DeepSeek、通义千问/百炼、Kimi、OpenRouter 和硅基流动。
可接入自定义 OpenAI Chat Completions 兼容接口、Claude Messages 兼容接口。
本机模型可填写本机 OpenAI 兼容服务地址（如 http://127.0.0.1:11434/v1）。
必须选择服务商实际开放的模型，API 地址和账户地域需匹配。
并非所有第三方网关或模型都兼容；返回400时可检查模型/地址，或关闭“分步检索”。
仅支持 Responses 的接口请选择自定义 Responses 兼容；OpenAI 默认使用 Responses。
ChatGPT/Claude 等网页会员登录凭据不是此处的 API Token。
“本机 Codex 登录”是可选路径，需使用者自行安装并登录 Codex。

【请求范围与费用】
费用与额度由使用者所选 AI 服务商收取和管理，拾光没有预置共享 Token。
发送问题时，问题、近期对话和为完成请求而读取的档案内容会发给该服务商。
分步检索每轮最多13次模型请求；上下文预算和最大输出 Token 可设置。
停止按钮会停止后续处理；服务商已接收的请求可能仍会计费。
界面显示服务商返回的 Token 用量，可能包括多次检索请求，不提供费用保证。
API 模式不自带网页搜索；不能把模型回答当作实时查证结果。

【简历】
先上传旧简历，在提问中说明简历涵盖到何时，再让助手结合后续成果生成新版本。
新文档另存为 Word 和 Markdown，并保留来源清单。旧文件不覆盖。
模型可能出错，请核对生成简历中的事实、日期和数字后再对外使用。
没有旧简历或时间范围不清晰时，助手应提示补充。

【数据与隐私】
新安装的数据默认保存在 %LOCALAPPDATA%\Shiguang\data，按 Windows 账户分开。
可在“设置 → 打开数据目录”查看实际位置。
旧版个人文件夹若已有 vault/diary.sqlite3，会继续使用原目录。
Token 使用 Windows DPAPI 加密保存在 credentials.dpapi，按 API 地址隔离。
普通 ZIP 备份不包含该凭据文件；更换电脑或 Windows 账户通常需要重新填写。
本机记录无需登录，不含使用分析上报或共享密钥。只有主动配置并启用 GitHub 同步后，选定资料才会上传自己的私有仓库。
Token 不会放进聊天请求的正文，只通过所配置接口的认证头发送。
API 请求不自动跟随跳转；云端 API 必须用 HTTPS，本机回环地址可用 HTTP。

【云文件】
通过已有 Google Drive、OneDrive、Dropbox 等客户端的本机同步目录导出附件。
写入本机同步目录不等于云端已上传完成；上传状态以网盘客户端显示为准。
不是账号配额查询或整库双向同步服务。

【备份、升级与卸载】
在设置中定期点击“导出完整备份”。完整备份含日记、待办、草稿、附件、对话与生成文档。
升级可运行新版安装包。程序与个人数据分开保存，升级不覆盖用户资料。
可从 Windows“已安装的应用”卸载拾光；卸载保留个人数据和加密 Token。
恢复备份前关闭应用并保留当前目录副本，按 ZIP 原结构恢复 vault/、generated/ 等文件。
分享给朋友请发送安装包或纯程序 ZIP，不要打包自己的数据目录。

【版本范围】
这是可分发的预览版，尚未包含自动更新、托盘提醒和内置网页检索。GitHub 同步为待完成应用注册和实际验证的可选预览功能。
此聊天原有的定时整理任务属于原用户，不包含在其他人的安装包里。
归档原文不会自动启动别人的 Codex 任务；可在应用助手里主动提问和复盘。

1.6 AI 连接
Codex 可读取本机登录、模型目录与额度，提供 GPT-6 Luna High、GPT-6 Astra Medium / High、GPT-6.1 Sol High 四个快捷组合。模型与推理强度会传给本次请求，不修改全局设置。目录不保证实际调用权限，其他 Codex 对话和项目不会自动同步。
API 服务新增 Gemini、Kimi、OpenRouter、硅基流动，支持模型目录读取、按服务商保存配置、百炼及 Kimi 地域选择。OpenAI 使用 Responses 支持 GPT-6 工具调用。完整连接步骤见 AI连接指南.md。

1.7：AI 日程草案与聊天
在拾光助手点击「帮我安排日程」，说明日期和要做的事。AI 起草后可以编辑、勾选，点击「确认写入日历」才添加；支持稍后确认，已有待办不自动改动。Enter 发送，Ctrl+Enter 换行。导出备份统一在设置中。修复从 Codex 桌面端启动时把桌面程序误认成 CLI 的连接失败。

【1.9 预览版：本机与可选同步】
无需登录即可继续本机记录。设置中的账号与同步仍待 GitHub App 注册和实际验证，发行包暂未内置有效注册信息；可直接跳过。有关权限、私有仓库、小附件限制与冲突处理，见随包 GitHub同步说明.md。
月历显示待办摘要、日记节选和附件名称；2026年中国大陆节假日标记可离线查看。附件标题不会打开文件，请使用明确的打开按钮。搜索默认列出全部附件，按上传时间由近到远排列。
本版已构建；未进行新版自动化测试、完整界面或真实双设备同步验收。
