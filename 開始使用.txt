拾光日曆 1.9.1 · 預覽版
每天一點，慢慢向前。

日期點選月曆；時間點選小時與分鐘，支援全天與 1 分鐘微調，無需手寫格式。

【安裝與開始】
適用于 Windows 10/11 64位。安裝后從桌面或開始菜單打開“拾光日曆”。
無需安裝 Python；使用服務商 API 時也無需安裝 Codex。
第一次打開可以先離線記錄，也可以進入“設定 → AI 服務與 Token 設定”。
本安裝包是未簽名的預覽版本，尚未經過全新電腦安裝和真實 API 調用測試。

【語言】
支持簡體中文、繁體中文和 English。安裝時可選擇語言，首次打開會沿用。
首次啟動頁或“設定”頂部選擇語言，再點“應用語言”，立即切換并自動記住。
切換前會儲存當前隨記；若有其他編輯窗口或正在處理檔案/請求，請先完成再切換。
界面、日曆日期、附件、搜索、設定和助手提示隨語言切換。
助手默認使用所選語言回復與生成文檔，也可在提問時明確指定其他語言。
原有日記、待辦、檔案內容和歷史對話保持原文；系統檔案選擇框的按鈕由 Windows 語言決定。

【日曆與附件】
選一天，記錄待辦和隨記。日記自動儲存在本機，無需另外歸檔。
綠色“回到今天”或 Ctrl+T 可跳回今天，今天的格子有明顯標記。
當天「附件」支援上傳檔案。標籤直接點選；在月曆中點選多天，或切換「連續日期」選開始與結束。
頂部“搜索”可查標題、正文、備注、隨記與待辦，離線可用。
掃描件暫不做 OCR；正文提取狀態會顯示在附件詳情。
基礎記錄、附件、搜索與備份均可離線使用。

【使用自己的 AI Token】
1. 在對應服務商的 API 控制臺創建自己的 API Key / Token。
2. 打開“設定 → AI 服務與 Token 設定”，選擇服務商。
3. 填 API 基礎地址、帳戶可用的模型名稱、自己的 Token，然后儲存。
4. 可點擊“檢查連接”：只發送簡短檢查文本，可能產生少量費用，不發送檔案。
5. 打開“拾光助手”，輸入問題，或點擊“更新我的簡歷”后發送。

預置 OpenAI、Claude、Gemini、DeepSeek、通義千問/百煉、Kimi、OpenRouter 和硅基流動。
可接入自定義 OpenAI Chat Completions 兼容介面、Claude Messages 兼容介面。
本機模型可填寫本機 OpenAI 兼容服務地址（如 http://127.0.0.1:11434/v1）。
必須選擇服務商實際開放的模型，API 地址和帳戶地域需匹配。
并非所有第三方網關或模型都兼容；返回400時可檢查模型/地址，或關閉“分步檢索”。
僅支持 Responses 的介面請選擇自定義 Responses 兼容；OpenAI 默認使用 Responses。
ChatGPT/Claude 等網頁會員登入憑據不是此處的 API Token。
“本機 Codex 登入”是可選路徑，需使用者自行安裝并登入 Codex。

【請求范圍與費用】
費用與額度由使用者所選 AI 服務商收取和管理，拾光沒有預置共享 Token。
發送問題時，問題、近期對話和為完成請求而讀取的檔案內容會發給該服務商。
分步檢索每輪最多13次模型請求；上下文預算和最大輸出 Token 可設定。
停止按鈕會停止后續處理；服務商已接收的請求可能仍會計費。
界面顯示服務商返回的 Token 用量，可能包括多次檢索請求，不提供費用保證。
API 模式不自帶網頁搜索；不能把模型回答當作實時查證結果。

【簡歷】
先上傳舊履歷，在提問中說明履歷涵蓋到何時，再讓助手結合後續成果產生新版本。
新文檔另存為 Word 和 Markdown，并保留來源清單。舊檔案不覆蓋。
模型可能出錯，請核對生成簡歷中的事實、日期和數字后再對外使用。
沒有舊簡歷或時間范圍不清晰時，助手應提示補充。

【資料與隱私】
新安裝的資料默認儲存在 %LOCALAPPDATA%\Shiguang\data，按 Windows 帳戶分開。
可在“設定 → 打開資料目錄”查看實際位置。
舊版個人檔案夾若已有 vault/diary.sqlite3，會繼續使用原目錄。
Token 使用 Windows DPAPI 加密儲存在 credentials.dpapi，按 API 地址隔離。
普通 ZIP 備份不包含該憑據檔案；更換電腦或 Windows 帳戶通常需要重新填寫。
本機記錄無需登入，不含使用分析上報或共享密鑰。只有主動設定並啟用 GitHub 同步後，選定資料才會上傳自己的私有儲存庫。
Token 不會放進聊天請求的正文，只通過所配置介面的認證頭發送。
API 請求不自動跟隨跳轉；云端 API 必須用 HTTPS，本機回環地址可用 HTTP。

【云檔案】
通過已有 Google Drive、OneDrive、Dropbox 等客戶端的本機同步目錄導出附件。
寫入本機同步目錄不等于云端已上傳完成；上傳狀態以網盤客戶端顯示為準。
不是賬號配額查詢或整庫雙向同步服務。

【備份、升級與卸載】
定期點擊“導出備份”。完整備份含日記、待辦、草稿、附件、對話與生成文檔。
升級可運行新版安裝包。程序與個人資料分開儲存，升級不覆蓋使用者資料。
可從 Windows“已安裝的應用”卸載拾光；卸載保留個人資料和加密 Token。
恢復備份前關閉應用并保留當前目錄副本，按 ZIP 原結構恢復 vault/、generated/ 等檔案。
分享給朋友請發送安裝包或純程序 ZIP，不要打包自己的資料目錄。

【版本范圍】
這是可分發的預覽版，尚未包含自動更新、托盤提醒和內置網頁檢索。GitHub 同步為待完成註冊與實際驗證的選用預覽功能。
此聊天原有的定時整理任務屬于原使用者，不包含在其他人的安裝包里。
歸檔原文不會自動啟動別人的 Codex 任務；可在應用助手里主動提問和復盤。

1.6 AI 連接
Codex 可讀取本機登入、模型目錄與額度，提供 GPT-6 Luna High、GPT-6 Astra Medium / High、GPT-6.1 Sol High 四個快捷組合。模型與推理強度會傳給本次請求，不修改全局設定。目錄不保證實際調用權限，其他 Codex 對話和項目不會自動同步。
API 服務新增 Gemini、Kimi、OpenRouter、硅基流動，支持模型目錄讀取、按服務商儲存配置、百煉及 Kimi 地域選擇。OpenAI 使用 Responses 支持 GPT-6 工具調用。完整連接步驟見 AI連接指南.md。

1.7：AI 日程草案與聊天
在拾光助手點擊「幫我安排日程」，說明日期和要做的事。AI 起草後可以編輯、勾選，點擊「確認寫入日曆」才新增；支援稍後確認，既有待辦不自動改動。Enter 傳送，Ctrl+Enter 換行。匯出備份統一在設定中。修復從 Codex 桌面端啟動時把桌面程式誤認為 CLI 的連線失敗。

【1.9 預覽版：本機與選用同步】
無需登入即可繼續本機記錄。設定中的帳號與同步仍待 GitHub App 註冊和實際驗證，發行包暫未內建有效註冊資訊，可直接跳過。權限、私有儲存庫、小附件限制與衝突處理見隨附的 GitHub同步说明.md。
月曆顯示待辦摘要、日記節選和附件名稱；2026年中國大陸假期標記可離線查看。附件標題不會開啟檔案，請使用明確的開啟按鈕。搜尋預設依上傳時間由近到遠列出全部附件。
